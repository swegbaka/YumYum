# Archived prototypes

These files belong to the earlier implementation. They are retained for reference and are not loaded by the current server.

- `legacy-server/`: old Express/Mongoose controllers, routes, models, and EJS views.
- `prototype/`: older frontend experiment, including duplicate sample assets.
- `legacy-data/`: superseded client-side filtering and ingredient data.

For the working website, edit `public/` and `backend/`. Do not run the archived `node.js` or follow its old connection settings.
